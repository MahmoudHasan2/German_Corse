مدرّب الألمانية — نسخة محمولة (ما بتحتاج تنزيل أي برنامج)
=====================================================

التشغيل
-------
1) فك ضغط الملف (ZIP) لمكان ثابت، مثلاً على سطح المكتب.
   مهم: لا تشغّل البرنامج من جوّا ملف الـ ZIP مباشرة.
   (إذا ويندوز منع التشغيل: كبسة يمين على ملف الـ ZIP ← Properties ← حط صح على Unblock ← OK، وبعدين فك الضغط.)
2) دبل كليك على:  Start German Coach.bat
   - أول مرة بياخد شي دقيقة لأنو بيجهّز قاعدة البيانات.
   - إذا طلعت رسالة "Windows protected your PC": اكبس More info ← Run anyway.
3) بينفتح المتصفح لحالو على:  http://127.0.0.1:8017
4) أول مرة: اعمل حسابك (الاسم، الإيميل، كلمة سر 10 أحرف أو أكتر).
5) تحت بصفحة الدخول في خانة "مفاتيح الذكاء الاصطناعي": حط مفتاح Groq (وGemini إذا بدك) واكبس "حفظ المفاتيح".

للإيقاف: دبل كليك على  Stop German Coach.bat
بيانات التعلّم بتنحفظ على نفس الجهاز (بمجلد  %LOCALAPPDATA%\GermanCoach) مو جوّا هالمجلد.

كيف تعمل مفتاح Groq (مجاني — الأهم: للتصحيح وللصوت)
-------------------------------------------------
1) افتح  https://console.groq.com  وسجّل دخول (بحساب Google أو بالإيميل).
2) من القائمة اختار  API Keys.
3) اكبس  Create API Key  واكتب أي اسم (مثلاً german-coach) ← Submit.
4) انسخ المفتاح فوراً (بيبدأ بـ  gsk_ ) — ما بيرجع يبيّن مرة تانية.
5) الصقه بخانة "مفتاح Groq" بصفحة الدخول ← حفظ المفاتيح.

كيف تعمل مفتاح Gemini (مجاني — اختياري)
-------------------------------------
1) افتح  https://aistudio.google.com  وسجّل دخول بحساب Google.
2) اكبس  Get API key  (بالقائمة) ← Create API key.
3) إذا سألك عن مشروع: اختار المشروع الموجود أو اعمل واحد جديد.
4) انسخ المفتاح — لازم يبدأ بـ  AIza
   انتبه: الشي اللي بيبدأ بـ  gen-lang-client-...  هاد اسم المشروع، مو المفتاح.
5) الصقه بخانة "مفتاح Gemini" ← حفظ المفاتيح.

ملاحظات
------
- كل شخص لازم يعمل مفاتيحه الخاصة. لا تشارك مفتاحك مع حدا.
- Groq المجاني بيسمح تقريباً بـ 5 تصحيحات بالدقيقة. إذا تأخّر شوي، البرنامج بيستنّى وبيعيد المحاولة لحالو.
- الميكروفون: المتصفح بيسألك أول مرة ← اكبس "سماح" (Allow).
